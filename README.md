# AegisLife Insurance Risk Analytics: Optimizing Loss Ratios & Underwriting Strategies

## 📌 Project Overview
This repository contains an end-to-end data analytics framework built for **AegisLife Insurance**. The project integrates advanced predictive modeling, structured database querying, data auditing, and dynamic visual intelligence to help actuarial and underwriting teams identify high-risk profiles, forecast claims severity, and prevent financial leakage.

Rather than looking at data in isolation, this framework replicates a modern financial intelligence workflow, mapping raw operational data to executive-level strategic decisions.

---

## 💼 The Business Problem
AegisLife faces substantial bottom-line exposure from inaccurate premium pricing, shifting demographic risk distributions, and operational blindspots in the claims handling process. 

This project aims to solve these core challenges by:
1. **Minimizing Loss Ratios:** Identifying customer cohorts with abnormally high claim frequencies to adjust premium margins.
2. **Streamlining Underwriting Efficiency:** Pinpointing key risk indicators (KRIs) to automate low-risk applications and isolate complex variables for human review.
3. **Data Integrity Assurance:** Constructing rigorous verification layers to ensure pricing decisions are based on accurate, audited operational metrics.

---

## 🛠️ Corporate Tech Stack & Workflows
The architecture spans five interconnected stages, mimicking real-world data team delivery:

* **Analytical Computation & Modeling (`AegisLife_Risk_Analysis.ipynb`):** An extensive Python data science framework utilizing Pandas, NumPy, and Scikit-Learn to simulate risk indices, run exploratory data analysis (EDA), and establish risk feature boundaries.
* **Database Query Architecture (`AegisLife Insurance Risk Analysis.sql`):** A robust production-grade SQL script implementing complex joins, subqueries, and window functions to aggregate financial exposure and segregate distinct structural layers of policyholder risk.
* **Audit & Validation Control (`AegisLife_Data_Validation_backup.xlsx`):** A comprehensive workbook designed for structural data verification, anomaly cross-checking, and pre-processing validation rules before pipelines feed downstream tools.
* **Dynamic Intelligence System (`AegisLife Insurance Risk Analysis.pbix`):** An interactive Power BI file built with a relational star-schema data model, custom DAX metrics, and dashboard layouts optimized for strategic monitoring.
* **Executive Summary (`AegisLife-Insurance-Risk-Analysis-Dashboard.pptx`):** A crisp presentation distilling technical data distributions into high-level business stories for executive board review.

---

## 📊 Core Business Metrics Addressed
* **Loss Ratio (%):** Total Losses / Earned Premiums
* **Frequency and Severity Indices:** Rate of occurrences vs. average financial impact per claim
* **Risk Score / Risk Index Tiering:** Segmented underwriting classifications (Low, Medium, Elevated, Critical)
